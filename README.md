# MiniBench

A lightweight cross-platform benchmarking tool for phones and computers, featuring on SoC theorical performance.

## Supported Platforms

| Platform     | Minimum Version    |
| ------------ | ------------------ |
| Android      | 7.0+               |
| Windows      | Windows 10 1703+   |
| Qt           | Qt 5.15+ / Qt 6.0+ |
| GTK          | GTK 4.14+          |
| macOS        | 11.0+ (AppKit)     |
| Mac Catalyst | 13.1+              |
